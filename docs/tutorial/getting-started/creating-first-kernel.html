Creating Your First Kernel

In this example, we will create a simple Kernel using DummyDevice to learn about the ViML interface.

Importing ViML​

Import ViML into your projects using the guidelines provided in this document.

The following CMakeLists.txt is an example of a project using ViML as an external library linked with executables.

cmake_minimum_required(VERSION 3.14)
project(example VERSION 1.0 LANGUAGES CXX)

# Set C++ standard
set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

include(FetchContent)

FetchContent_Declare(
        flexisim
        QUIET
        GIT_REPOSITORY git@github.com:Arash1381-y/undefined.git
        GIT_TAG main
        SOURCE_DIR ${CMAKE_SOURCE_DIR}/ext/flexisim
)

FetchContent_MakeAvailable(flexisim)

add_executable(first_test src/main.cpp)
target_link_libraries(first_test flexisim)

where main.cpp is placed in the src directory.

Including the Device Module​

Import the Device module by including:

#include <flexisim/device.hpp>

Creating a Dummy Device​

Device types serve as the main interface for ViML. Each Device comes with its own set of characteristics:

  1. A dedicated namespace matching the device name (DummyDevice must be defined under namespace flexisim::dummy_device).
  2. Device types.
  3. Actions (prefixed with Action__).

To get familiar with devices, let's create our first DummyDevice. Use the createDevice factory method with no input arguments as follows:

int main() {
    const auto dummy_device = flexisim::createDevice();
}

createDevice returns a shared_ptr<flexisim::Device>, which will be used by the kernel in the next step.

Creating a Kernel​

A Kernel is a module that manages a group of devices. You can describe your application using kernel APIs. Include the kernel using the following directive:

#include <flexisim/kernel.hpp>

The Kernel constructor accepts a vector of device addresses as input. Let's create our kernel with the dummy device we created in the previous section:

int main() {
    const auto dummy_device = flexisim::createDevice();
    auto kernel = flexisim::Kernel({dummy_device});
}

Creating an Event​

Events are sets of actions with specified dependencies. Each event defines a group of actions that can be executed in order, out of order, in parallel, or sequentially. The important point is that the programmer does not impose a specific order on the actions within the event; the execution order is determined by the kernel and devices themselves.

Creating an Action​

To use DummyDevice actions, include the following header:

#include <flexisim/devices/dummy_device.hpp>

This will import device types and actions.

Calling a Dummy Action​

Now we can call a dummy action. For example:

int main() {
    const auto dummy_device = flexisim::createDevice();
    auto kernel = flexisim::Kernel({dummy_device});
    // Passing an empty list of arguments
    flexisim::dummy_device::Action__dummy_no_arg({});
}

Although the action function is called manually, in most cases, we want the kernel to be responsible for calling actions at the correct time based on the determined dependency graph. Therefore, we need a wrapper for every possible action.

This wrapper is named Action. Each action is defined by three parameters:

  1. Action device address
  2. Action function address
  3. List of arguments

For instance, an action calling flexisim::dummy_device::Action__dummy_no_arg is defined as:

    flexisim::Action a1(dummy_device, flexisim::dummy_device::Action__dummy_no_arg, {});

Pushing an Event​

Now that we have our action, we can push it to the kernel using kernel.pushEvent, which accepts two arguments:

  1. A list of devices that the event depends on (these devices must not be busy when this event starts execution).
  2. A list of actions.
int main() {
    auto dummy_device = flexisim::createDevice();
    auto kernel = flexisim::Kernel({dummy_device});

    flexisim::Action a1(dummy_device, flexisim::dummy_device::Action__dummy_no_arg, {});
    kernel.pushEvent({}, {&a1});
}

By defining events, we can program our own scheduler.

Running Events​

After defining a set of events, simply call Kernel.run() to execute the actions and events in the determined order.

Complete Example​

Here is the complete code for this section:

#include <flexisim/devices/dummy_device.hpp>
#include <flexisim/device.hpp>
#include <flexisim/kernel.hpp>

int main() {
    auto dummy_device = flexisim::createDevice();
    auto kernel = flexisim::Kernel({dummy_device});

    flexisim::dummy_device::Action__dummy_no_arg({});

    flexisim::Action a1(dummy_device, flexisim::dummy_device::Action__dummy_no_arg, {});
    kernel.pushEvent({}, {&a1});

    // Run the kernel to execute events
    kernel.run();
}
