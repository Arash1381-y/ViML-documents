Building ViML

This section provides a step-by-step guide on how to build the ViML tool. It covers the necessary dependencies, setup instructions, and build process.

Getting the Code​

You can clone the repository from github using following command:

git clone git@github.com:Arash1381-y/undefined.git

Build System​

ViML uses CMake as its primary build system. The following options are available to configure the build process:

CMake Configuration Options​

OptionDescriptionDefault
WITH_TESTSEnable building test casesON
WITH_EXAMPLESEnable building example programsON
WITH_PLAYGROUNDEnable the playground executable for testing (experimental)OFF

CMake allows you to customize the build process by enabling or disabling specific features using options. By using the provided options, you can prevent unwanted targets or dependencies, optimizing the build for your needs.

note

To configure and build the ViML project with specific options, use the -D flag when running cmake.

mkdir build
cd build
cmake .. -DWITH_TESTS=ON -DWITH_EXAMPLES=OFF -DUSE_LOCAL_PIM_RAMULATOR=ON -DWITH_PLAYGROUND=OFF

You can also change the original CMakeLists.txt in project root.

Running CMake​

Similar to most CMake-based projects, you must create a build directory and run cmake .. to configure the project before building.

This step generates the necessary build files based on the system configuration.

mkdir build
cd build
cmake ..
warning

cmake uses your Git credentials to access external repositories. If you cannot access a repository via cmake, you can manually clone the repository and modify CMakeLists.txt to use the local repository instead.

for example replace following FetchContent:

FetchContent_Declare(
        pim-ramulator
        GIT_REPOSITORY git@github.com:Arash1381-y/pim-ramulator.git
        GIT_TAG main
        SOURCE_DIR ${CMAKE_SOURCE_DIR}/ext/pim-ramulator
)

with a local repository clone:

FetchContent_Declare(
        pim-ramulator
        GIT_REPOSITORY file:///path/to/local/repository
        GIT_TAG main
        SOURCE_DIR ${CMAKE_SOURCE_DIR}/ext/pim-ramulator
)

Building Targets​

Once the configuration is complete, you can compile the project using the generated Makefile. The make command allows you to specify the number of CPU cores to speed up the build process.

cd build
make -j$(nproc)

Replace $(nproc) with the number of available CPU cores or use $(nproc) directly (on Linux/macOS) to automatically detect the optimal number.
